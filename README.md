# 🎯 Quiz Master

**Quiz Master** is a sleek, modern, and interactive quiz platform designed for students and educators alike. Built completely in Python using the **Flet** framework, it offers a responsive cross-platform UI for creating, managing, and taking live quizzes seamlessly.

---

### ✨ Key Features

* 📊 **Dashboard Analytics:** Real-time stats on active quizzes, student completion rates, and quick draft management.
* 📚 **Quiz Library:** Browse, search, and filter quizzes by subject categories or custom topics.
* ⚡ **Live Quiz Joining:** Instant quiz access using unique, generated quiz codes (e.g., `BIO101`, `MATH101`).
* ✏️ **Interactive Quiz Builder:** Create and customize new quizzes, modify questions, set timers, and adjust difficulty levels.
* 🎯 **Smart Search & Filters:** Fast, real-time search across titles and subjects without losing interface focus.
* 🎨 **Modern Desktop & Mobile UI:** Fluid user experience featuring custom cards, floating action buttons, and responsive view stacks.

---

### 🛠️ Built With

* **[Python](https://www.python.org/)** – Core application logic
* **[Flet](https://flet.dev/)** – Flutter-powered UI engine for Python
